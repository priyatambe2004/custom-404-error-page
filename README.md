# Lumio – Custom 404 Error Page

A modern, responsive **404 Error Page** designed to provide a friendly and helpful experience when users visit a page that cannot be found. The page features a clean layout, clear messaging, and easy navigation back to the homepage.

## ✨ Features

- **Custom 404 Design** – A clear and user-friendly error message.
- **Modern UI** – Clean typography, attractive styling, and a polished layout.
- **Responsive Layout** – Adapts to desktop, tablet, and mobile screens.
- **Homepage Navigation** – Provides a link to return to the main page.
- **CSS Illustration** – Uses styling and visual elements to make the error page engaging.
- **Consistent Branding** – Designed as part of the Lumio web project.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox and CSS Grid
- Responsive Web Design

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in your browser to view the homepage.
4. Open `404.html` to view the custom error page.

## 🎯 Project Objective

The goal of this project was to practice layout design, typography, responsive styling, and CSS-based visual elements while creating a useful error page that helps users navigate back to the homepage.

## 📚 Learning Outcomes

- Creating a responsive page layout.
- Using CSS Flexbox and Grid for alignment.
- Improving typography and visual hierarchy.
- Designing a user-friendly error page.
- Linking pages for better website navigation.
